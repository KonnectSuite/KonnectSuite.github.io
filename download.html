Two installers, one decision

AryaCode is the app: the same DeepSeek Harness base, a plugin-first install, and the Arya plugin market already there. AryaAI is the retired line — 0.12.19 is its final build, kept here for installs that want to stay put.

Both are Windows x64 desktop apps on DeepSeek Harness 0.2.1-rc.3. Both are unsigned, both can check for updates from inside the app, and neither one touches the other’s chats, settings or plugins.

Running both is supported, and quiet AryaCode keeps its data in %USERPROFILE%\.aryacode, separate from AryaAI. Installing one does not migrate, overwrite or delete the other’s chats, settings or plugins.

Before you install

Three things Windows will tell you

Preview software, unsigned installer — read before you install

  • There is no code-signing certificate on either installer. Windows SmartScreen shows “Windows protected your PC” on first run: choose More info, then Run anyway. Verify the download against the SHA-256 below if you want certainty about the file itself.
  • Windows 10 or 11, x64. There is no ARM64 or 32-bit build.
  • Preview quality applies to the engineering capability. The limits page names the app and bundle versions each published limit was written against; if a bundle on your install is a different version, read its release notes for the limits that version carries.
  • AryaCode is on a nightly channel. Builds move faster and can regress. AryaAI is quieter — but 0.12.19 is frozen, and it will not improve.

Verify the download

Compare the hash before you run it

The SHA-256 values on this page are the digests GitHub reports for the uploaded assets. In PowerShell, run the command for the file you downloaded and compare the last line.

PowerShell · AryaCode 
Get-FileHash .\aryacode-*-win-x64-unsigned.exe -Algorithm SHA256

Expected 681eaa8d0b8a9dcfe80de39a896cf092494fcad782f7baea40348abb91ca2eb6

PowerShell · AryaAI 
Get-FileHash .\aryaai-*-win-x64-unsigned.exe -Algorithm SHA256

Expected eab95a5d0ad27f75fc4c95724ce3c1dd959a5f3ff22edca8947379b65399592f
