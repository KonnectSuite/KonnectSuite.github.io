# AryaAI 0.9.0

AryaAI 0.9.0 adds built-in desktop and FactoryTalk View workflows on DeepSeek Harness 0.2.0-rc.2.

- Includes Native Window 0.1.2 for docking Windows applications beside Arya conversations. Elevated applications require separately approved helper elevation.
- Includes FactoryTalk View Use 0.1.4 with eleven tools and an engineering skill: read-only workspace discovery, guidance for missing ME exports, display and tag analysis, guarded change preparation, and Studio import verification.
- Selects both bundles by default and manages them through Plugin Market. Adoption respects subsequent user removal; bundled resources remain available for restoration.
- Repairs the DeepSeek Chat caption layout and makes Reload act consistently.
