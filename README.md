# KonnectSuite.github.io

AryaCode's product site: the pages you browse here plus the legacy AryaAI desktop
update feed. GitHub Pages serves the channel metadata under
`dsh-desk/<release id>/feeds/<target>/nightly.yml`; the installer binaries are
release assets, referenced from that metadata by absolute URL because Pages
refuses files over 100 MB. AryaCode itself ships from
[github.com/KonnectSuite/AryaCode](https://github.com/KonnectSuite/AryaCode).
