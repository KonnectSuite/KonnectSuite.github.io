Inside the installer

It knows the difference between reading a project and touching a controller

Seven of these servers ship inside AryaAI and run on the Python or Node the application carries, so the PC does not need its own toolchain for them. The eighth, FactoryTalk Optix Tools, talks to Optix Studio’s own service on this PC. Enable a row from the MCP list or the slash menu; the list stays open while you switch a server.

The point of the desk is that the answer does not need a support contract. Each row below is a capability that would otherwise be a phone call, a ticket queue, or a colleague who happens to be free — and AryaAI is meant to be the line you reach instead.

The whole picture, up front

What each server reaches — and where it stops

An agent tool that cannot see its target says so, and AryaAI still starts. A missing factory tool reports itself in the MCP panel; it does not stop the application opening.

In detail

Each server, on its own terms

Studio 5000 Projects

You point it at an export, or at an offline copy of an .acd. It gives you the controller summary, tags, UDTs, add-on instructions, modules, programs and routines, with cross-references and static checks. Ladder comes back as text with the rung comments attached — and the built-in Logix viewer draws the same ladder beside the chat.

It can also read a live controller: its mode, tag values and diagnostics. Through the Logix Designer SDK it imports an edited export into a new offline .acd and builds it, reporting the failing stage and the SDK diagnostics when a build does not pass.

Uploading the controller, changing its mode, and downloading are separate tools, and each one raises its own approval prompt against a named controller. No request from you authorizes an online edit, a force, a bit toggle or a data write.

The Studio 5000 and Logix page

Ignition SCADA

Reads an Ignition 8.1 export or an 8.3 project directory: tags, Perspective views, scripts, UDTs, alarm pipelines and named queries. The copy AryaAI ships does not talk to a live gateway and does not write tags.

SCADA ↔ PLC Bridge

This is the one that answers the question you actually get asked: does this HMI tag exist in the program? It maps the two projects, follows a single tag from its OPC item path into the rungs that use it, and lists the tags that exist on only one side.

IronPLC Compiler

For IEC 61131-3 Structured Text, when you want a check, a compile and a run without opening a vendor IDE. It understands the IEC standard and the dialects used by CODESYS and TwinCAT.

It is a soft-PLC. It is not a stand-in for MotionWorks IEC or Studio 5000.

NetLogic Cheat Sheet

Answers FactoryTalk Optix NetLogic questions from a fixed copy of Rockwell’s public cheat sheet — the categories, the pages, and the C# snippets that go with them.

It does not open an Optix project.

FactoryTalk Optix Tools

The one engineering row that cannot be packed into the installer, because it connects to Optix Studio’s own service on this PC. Turn the row on when that service is up. Turn it off and AryaAI stops waiting for it.

The desktop path

Windows Computer Use looks before it clicks

Some work has no file format: go online, watch a trend, open the cam editor. Computer Use is how the agent reaches an application that has no project plugin yet — including Studio 5000 and FactoryTalk View — and the MotionWorks IEC actions that have no file equivalent.

  • It finds windows and reads UI Automation elements
  • It sees the screen with OCR in English and Chinese
  • Mutating automation is refused while the kill switch is on

It can look while it cannot act Screenshots, OCR and the UI Automation tree keep working with the kill switch on. Skills & MCP puts the kill switch and the dry run beside each other, with Save and restart.

Turning the kill switch off means real clicks on this desktop It is a choice recorded for that session, and a click that already reached the application is not pretended to have been undone.

Face recognition and the keylogger are not enabled The experimental desktop driver that can operate a background window is in the source tree and is not mounted.

Bring your own

The MCP panel, and servers of your own

The slash menu has MCP. Turn a shipped server on or off without leaving the chat, add a server of your own — a local program, or an HTTP endpoint — and remove the ones you added. Shipped servers are not removed from that button.

Switch a row

Enable an engineering server only when you need it. Turned off, AryaAI does not wait for it and does not fail without it.

Add your own

Point at a local program or an HTTP endpoint. Your servers are yours, and they are kept separately from the ones we ship.

Replace a specialty

If it can be a plugin, it is a plugin. A vendor arrives as a plugin, and a plant turns off the ones it does not use.

Where stepping back from the desk is recorded Reading a project and changing a running controller are different acts. Uploading the controller, changing its mode and downloading are their own tools, each asking you first and naming the controller it will touch — never implied by “edit the project.”

Install it, then switch on one row

Seven of the eight engineering servers ship in the installer, with nothing extra to download. FactoryTalk Optix Tools is the exception — it uses Optix Studio’s own service on this PC. Windows Computer Use and ComfyUI MCP start with the app; the others wait until you switch them on.
