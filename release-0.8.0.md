# AryaAI 0.8.0

AryaAI 0.8.0 adds Projects on DeepSeek Harness 0.2.0-rc.2.

- Create named projects above Workspaces and select several source folders in one popup.
- Start chats beneath a project, search projects, change view options, and edit folders.
- Show project chats once in the sidebar; disabling Projects restores their workspace listing.
- Ship the pinned Projects 0.1.7 plugin with every installation, without requiring private repository access.
- Add Projects when upgrading from 0.7.0 while preserving personal plugins and previously removed optional bundles.
- Repair plugin reloads that could interrupt workspace and Images chat services.

Multi-folder Workspace Write is supported on Windows. Other platforms retain writes in the primary chat folder. Existing sessions and settings are retained.

The Windows x64 installer is unsigned.

Source: [KonnectSuite/AryaAI commit 1a3ede42651198e8e438dce88d8841f4875252ae](https://github.com/KonnectSuite/AryaAI/commit/1a3ede42651198e8e438dce88d8841f4875252ae).
