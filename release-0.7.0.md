# AryaAI 0.7.0

AryaAI 0.7.0 adds community-powered image conversations and user-managed shipped plugins on DeepSeek Harness 0.2.0-rc.2.

- Create and edit images through pinned dsh-image-gen tools using configured local or hosted providers.
- See ComfyUI server status and lifecycle progress; start, stop or restart from Images.
- Keep recent runs and local photos below chat, with multi-select ZIP download and deletion.
- Receive pinned billion-context and the shipped community plugin roster with each install.
- Enable, disable, remove and restore optional Arya-authored and community bundles through plugin controls. Core runtime and management stay protected; shared installer files remain available for restoration.
- Existing Desktop profiles receive the roster once; later removals are preserved. Sessions and personal settings are retained.
- Correct rebuild failures from directory-picker types and separate product change pushes from installer publication.

The Windows x64 installer is unsigned. Configure image providers and compatible local workflows before generation; Arya does not install model weights.
